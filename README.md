# Smart Clips — YouTube Smart Clip Player

PWA che riproduce in sequenza automatica solo gli spezzoni utili di un video YouTube, a partire da un JSON:

```json
{"video_id": "ID_VIDEO", "clips": [{"start": 0, "end": 0, "label": "MM:SS-MM:SS", "title": "Argomento"}]}
```

Online: https://ianes1978.github.io/SmartClips/
